# KSE 글로벌 모션 프로토타입 설계

## 목적

KSE를 일본 배송 전문업체로 고정하지 않고, 한국과 일본에서 검증된 자체 인프라를 기반으로 세계를 연결하는 크로스보더 물류 브랜드로 재정의한다. 방문자는 물류 용어를 읽기 전에 상품 하나가 주문에서 해외 고객 배송까지 이동하는 과정을 직관적으로 이해해야 한다.

## 핵심 포지셔닝

> 한국과 일본의 자체 인프라. 전 세계를 연결하는 파트너 네트워크.

영문 보조 문구는 `Owned infrastructure in Korea & Japan. Connected to the world.`를 사용한다. 한국과 일본은 직접 운영 거점으로 선명하게 표현하고, 그 외 지역은 파트너 네트워크로 명확히 구분한다. 전 세계 자체 물류센터를 보유한 것처럼 오해시키는 표현은 사용하지 않는다.

## 경험 콘셉트

`One Shipment, One World`를 중심 콘셉트로 사용한다. 하나의 KSE 패키지가 모든 장면을 관통하는 연속 오브젝트가 되어 주문, 풀필먼트, 통관, 복합운송, 라스트마일 배송을 연결한다. 일본 노선은 전체 정체성이 아니라 KSE의 속도와 운영 역량을 입증하는 대표 사례로 배치한다.

## 브랜드 성격

- 정확한: 과장보다 운영 구조와 실제 강점을 명확하게 보여준다.
- 역동적인: 물류가 실제로 이동하고 연결되는 감각을 전달한다.
- 든든한: 화려한 효과보다 안정적인 인프라와 실행력을 중심에 둔다.

기존 KSE 로고와 네이비·블루 계열을 유지한다. 검정·금색의 고급화, 유리 효과, 그라디언트 텍스트, 의미 없는 카드 그리드는 사용하지 않는다. 밝은 항만의 하늘색, 바다의 코발트, 야간 운영을 암시하는 짙은 네이비를 장면 전환에 활용한다.

## 스토리보드

### 1. Hero — One Shipment, One World

새벽의 한국 항만과 물류센터가 하나의 넓은 장면으로 열린다. 중앙의 패키지가 움직이기 시작하면 한국과 일본의 두 거점이 실선으로 연결되고, 그 바깥으로 세계 파트너 노선이 점선으로 확장된다. 첫 화면에는 핵심 포지셔닝과 `글로벌 물류 상담` CTA만 둔다.

### 2. Unified Commerce

Qoo10, Amazon, Shopify 등 판매채널을 직접 로고 그리드로 나열하지 않고 주문 신호가 하나의 흐름으로 합쳐지는 장면으로 표현한다. 패키지 위에 주문 정보가 결합되며 OMS 통합, 주문 자동 수집, 재고 가시성을 설명한다.

### 3. Smart Fulfillment

패키지가 KSE 물류센터의 컨베이어에 진입한다. 입고, 검수, 보관, 포장, 출고가 하나의 연속 동선으로 이어지고 각 단계의 장점은 짧은 동사형 문장으로 표시한다. 실제 KSE 센터 사진은 신뢰 근거로 사용하고, 생성 이미지는 장면 연결과 확장에 사용한다.

### 4. Customs Intelligence

바코드 스캔이 국경 게이트를 여는 전환 효과가 된다. 일본 자체 통관면허, 전문 통관 인력, 자체 시스템을 핵심 근거로 보여준다. 한국 통관은 협력 관세법인을 통한 운영이라는 사실과 혼동되지 않도록 카피를 구분한다.

### 5. Multimodal Network

화물의 크기, 속도, 비용 조건에 따라 경로가 선박, 항공기, 트럭으로 분기된다. 선박은 수평 이동, 항공기는 원거리 호, 트럭은 라스트마일 곡선을 담당한다. 사용자가 스크롤하면 패키지가 적절한 운송수단으로 자연스럽게 인계된다.

### 6. Proven in Japan

부산·하카타와 한국·일본 주요 거점을 확대해 `D+3/D+4`, 당일 주문·포장·출항 등 검증된 일본 서비스의 강점을 보여준다. 이 구간만 일본을 강하게 강조하며 `글로벌 확장의 첫 번째 완성 노선`으로 정의한다.

### 7. Connected to the World

카메라가 뒤로 빠지며 세계 지도가 나타난다. 한국·일본은 채워진 노드, 파트너 지역은 선과 점으로 나타난다. 해상·항공 포워딩과 제3국 운송을 포함한 연결 능력을 설명하되, 직접 운영 거점과 파트너 범위를 시각적으로 구분한다.

### 8. Conversion

목적지, 화물 유형, 월 예상 물량을 선택하는 짧은 상담 폼으로 끝낸다. 프로토타입에서는 실제 전송 대신 유효성 검사와 성공 상태까지 구현한다.

## 모션 원칙

- 스크롤을 가로채지 않고 기본 스크롤 위에서 장면을 고정하거나 전환한다.
- 한 화면에서 주인공 오브젝트는 패키지와 운송수단 두 종류를 넘지 않는다.
- 모션은 정보의 인계와 거리 이동을 설명할 때만 사용한다.
- `prefers-reduced-motion`에서는 고정 이미지와 짧은 페이드로 대체한다.
- 모바일에서는 장면 깊이를 줄이고 수평 이동을 세로 타임라인으로 재구성한다.
- 핵심 콘텐츠는 자바스크립트 실행 전에도 읽을 수 있어야 한다.

## 이미지 생성 방향

GPT Image 2.0으로 다음 자산을 일관된 포토리얼 2.5D 광고 비주얼로 제작한다.

- 한국 항만과 스마트 물류센터가 연결된 와이드 히어로 배경
- KSE 컬러를 적용한 컨테이너선, 화물기, 배송 트럭
- 동일한 형태와 라벨을 유지하는 주인공 패키지
- 컨베이어·바코드 스캔·통관 게이트 장면
- 데스크톱과 모바일용 장면별 정지 대체 이미지

로고와 텍스트는 생성 이미지에 포함하지 않는다. KSE 로고는 공식 자산을 사용하고, 글자는 HTML로 렌더링한다. 기존 사이트의 선박·항공기·창고 이미지는 사실 관계와 형태 참고용으로만 사용한다.

## 기술 방향

- Vite + React + TypeScript
- GSAP ScrollTrigger와 CSS transform 기반 2.5D 레이어
- SVG 경로를 이용한 항로와 패키지 진행 상태
- Vitest + Testing Library로 콘텐츠·접근성·감속 모드 테스트
- 브라우저에서 데스크톱·태블릿·모바일 시각 검증

## 성공 기준

- 첫 10초 안에 KSE가 글로벌 크로스보더 물류사임을 이해할 수 있다.
- 일본이 강점으로 보이되 사업 범위 전체로 오해되지 않는다.
- 주문부터 배송까지의 물류 단계를 스크롤만으로 설명할 수 있다.
- 모션 감소 환경에서도 정보 손실 없이 읽을 수 있다.
- 모바일에서 가로 스크롤, 텍스트 겹침, 44px 미만 터치 영역이 없다.
- 초기 핵심 장면 이미지는 최적화하고 나머지는 지연 로딩한다.

## 범위 제외

- 실제 OMS 로그인과 주문 데이터 연동
- 실시간 운임 산출 및 결제
- 전체 회사소개·채용·고객지원 하위 페이지
- 실제 상담 API 전송
- 다국어 번역 완성본
