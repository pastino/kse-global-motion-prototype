# KSE 글로벌 모션 프로토타입 시각 QA

## 검토 환경

- 데스크톱: 1440 × 1000
- 모바일: 390 × 844
- 브라우저 콘솔 오류·경고: 없음
- 모바일 가로 오버플로: 없음

## impeccable 검토

- 기존 KSE 로고와 네이비·블루 정체성을 유지했다.
- 검정·금색, 그라디언트 텍스트, 반복 카드, 의미 없는 배지 사용을 피했다.
- 모션은 주문 합류, 통관 통과, 운송수단 이동, 네트워크 연결에만 사용했다.
- 일본은 전체 브랜드 정체성이 아니라 검증된 대표 노선으로 분리했다.
- 한글 제목의 외톨이 글자와 불균형 줄바꿈을 `text-wrap: balance`와 `word-break: keep-all`로 수정했다.
- 한 화면에 하나의 주인공 장면을 유지하고 불필요한 UI 장식을 제거했다.

## ui-ux-pro-max 검토

- `prefers-reduced-motion`에서 GSAP 실행을 생략하고 정적 장면을 제공한다.
- 자체 거점과 파트너 네트워크를 색상뿐 아니라 실선·점선·범례로 구분했다.
- 링크·버튼·모바일 메뉴의 최소 터치 높이를 44px 이상으로 유지했다.
- 스킵 링크, 시맨틱 섹션, 폼 레이블, 성공 상태 `role=status`를 적용했다.
- 모바일에서 물류 단계를 세로 흐름으로 변환하고 운송 장면을 정적 포스터 구조로 제공했다.
- 히어로와 창고 배경을 WebP로 최적화하고 아래쪽 운송 이미지는 지연 로딩했다.

## 반복 수정 내역

1. 제목 최대 폭을 조정해 데스크톱의 한 단어 고립 문제를 제거했다.
2. 일본 성공 노선 제목 크기를 낮춰 정보와 이미지의 균형을 맞췄다.
3. 생성 원본과 참조 이미지를 배포 폴더에서 분리해 빌드 크기를 줄였다.
4. 투명 PNG 운송 레이어를 WebP로 변환해 배포 자산을 약 1.5MB에서 더 경량화했다.
5. 세계 지도상의 미확인 도시명을 권역명으로 교체해 직접 거점으로 오해될 가능성을 제거했다.

## 검증 결과

- Vitest: 3개 파일, 4개 테스트 통과
- TypeScript + Vite 프로덕션 빌드: 통과
- 상담 폼: 필수 입력, 성공 상태 전환 확인
- 직접 운영과 파트너 네트워크 표현: 구분 확인
