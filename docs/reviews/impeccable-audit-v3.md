# Impeccable 기술 감사 v3 — 글로벌 네트워크 모션

대상: `WorldRoute.tsx`, `useJourneyMotion.ts`, `global.css`

## 결과

| 항목 | 결과 | 확인 내용 |
|---|---|---|
| 정보 위계 | 통과 | 네트워크 제목 → 지도 상태 → 자체 거점/파트너 범례 순서가 명확함 |
| 모션의 의미 | 통과 | 움직이는 점이 장식이 아니라 실제 연결 항로의 방향을 설명함 |
| 대비 | 수정 후 통과 | 누락된 `.dark-section` 배경을 복구해 흰색 제목과 지도 라벨 대비 확보 |
| 반응형 | 통과 | 390px에서 가로 오버플로 없음, 상태 수치와 보조 라벨을 단계적으로 생략 |
| 접근성 | 통과 | SVG에 구체적 대체 설명 제공, 모션 감소 환경에서 경로 이동과 포인터 모션 제거 |
| 성능 | 통과 | 별도 3D 런타임 없이 SVG와 transform/opacity만 사용 |

## UI/UX Pro Max 검증

- 앵커 이동에는 기존 `scroll-behavior: smooth`를 유지한다.
- 모바일에서 수평 스크롤을 만들지 않는다.
- `prefers-reduced-motion`에서 긴 스크롤 장면은 정적 콘텐츠로 교체하고, 지도 이동 펄스도 숨긴다.
- 한 화면에서 움직임의 초점은 항로 펄스와 포인터 패럴랙스로 제한한다.

## 반복 수정 내역

1. 정적 SVG 지도에 항로 펄스, 상태 바, 경로 그리드를 추가했다.
2. 데스크톱 시각 검증에서 네트워크 배경 클래스 누락을 발견했다.
3. `.dark-section`의 배경과 텍스트 색을 명시해 대비를 복구했다.
4. 390px 모바일에서 지도를 세로형으로 재배치하고 불필요한 라벨을 줄였다.
5. 데스크톱·모바일 오버플로, 포인터 반응, 빌드와 테스트를 재검증했다.
