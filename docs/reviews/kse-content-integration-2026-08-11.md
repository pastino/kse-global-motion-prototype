# KSE 콘텐츠 통합 기준

## 핵심 포지셔닝

- 한국과 일본의 자체 인프라는 KSE의 직접 운영 역량으로 표현한다.
- 그 외 지역은 자체 거점으로 과장하지 않고 글로벌 파트너 네트워크로 구분한다.
- 일본 특송은 회사의 전체 정체성이 아니라 글로벌 실행력을 증명하는 대표 사례로 배치한다.

## 미디어 사용

- 일본 거점 사진: KSE 공식 풀필먼트 페이지에서 제공하는 현장 이미지 사용.
- 브랜드 필름 포스터: KSE 공식 한국어 홍보 영상의 YouTube 썸네일 사용.
- 모션용 운송수단: 기존 GPT Image 생성 에셋을 투명 레이어로 사용.
- 실제 회사 로고와 현장 사진은 생성 이미지로 대체하지 않는다.

## 모바일 모션 원칙

- 데스크톱의 긴 고정 스크럽을 모바일에 그대로 축소하지 않는다.
- 풀필먼트 → 통관·육상 → 항공·해상 세 장면만 한 화면 단위로 보여준다.
- 장면은 일반 스크롤과 가벼운 진입 모션으로 진행하며 스크롤을 가로채지 않는다.
- `prefers-reduced-motion`에서는 모션 무대를 숨기고 같은 정보를 정적 단계 목록으로 제공한다.
- 모든 내비게이션과 CTA의 터치 영역을 최소 44px로 유지한다.
