# KSE 물류 모션 방향성 감사

## 기준

화면 좌표가 아니라 각 자산의 실제 전면을 기준으로 전진 방향을 정한다.

| 운송수단 | 자산의 전면 | 기존 이동 | 판정 | 수정 이동 |
|---|---|---|---|---|
| 리치 스태커 | 작업 붐·컨테이너 방향인 오른쪽 | 오른쪽 | 유지 | 오른쪽 |
| 측면 트럭 | 운전석이 있는 오른쪽 | 왼쪽 | 역주행 | 오른쪽 |
| 탑뷰 트럭 | 운전석이 있는 위쪽 | 아래쪽 | 역주행 | 위쪽 |
| 탑뷰 선박 | 선수의 뾰족한 쪽인 위쪽 | 아래쪽 | 역주행 | 위쪽 |

## 전환 규칙

1. 측면 장면에서는 화물이 왼쪽에서 들어와 오른쪽으로 빠져나간다.
2. 카메라가 탑뷰로 바뀌면 전진축을 위쪽으로 통일한다.
3. 탑뷰 트럭과 선박은 같은 축을 유지해 매치컷의 공간 연속성을 보존한다.
4. 서비스 카드만 차량의 반대 방향으로 움직여 도로를 통과하는 속도감을 만든다.
5. 모션 감소 설정에서는 방향 전환을 포함한 스크롤 애니메이션을 제거한다.

## 브라우저 검증

- 측면 트럭 중심 X: `917 → 1100 → 1277px`
- 탑뷰 트럭 중심 Y: `314 → 104 → -105px`
- 탑뷰 선박 중심 Y: `343 → 158px`

모든 운송수단이 자산의 전면 방향으로 이동함을 확인했다.
